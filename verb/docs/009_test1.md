# Verb: `test1`

- **Kind:** canonical
- **Availability:** universal
- **`--dry-run`:** `./runbox/runbox .live -- env NEXTEST_FILTER='<filter>' verb/test.d/l1_filter`

### Command

```bash
./verb/test1 <nextest-filter>
```

Delegates to the launcher `runbox/runbox` (shared engine, `family_dev/default`) with a `.live` payload, building the container image if needed. The container executes `verb/test.d/l1_filter`, which runs `RUSTFLAGS="-D warnings" cargo nextest run --all-features -E "<filter>"`. No doc tests or clippy — use `./verb/test` for the full suite.

### Layers

| Layer | Context | Docker | `CARGO_NET_OFFLINE` | Default |
|-------|---------|--------|---------------------|---------|
| runbox | host → container via `runbox/runbox .live -- <payload>` | yes | yes (inside container) | yes — only path |

### Notes

`verb/test1 <filter>` is the **mandatory** choice for targeted verification. Running `./verb/test` (full suite) to check a single test is a performance violation per `rulebook.md § Test Execution : Container-Only Testing` — `verb/test1` avoids nextest full-suite + clippy + doc-test overhead.

The filter is a nextest filter expression passed as `NEXTEST_FILTER` env var to the container. `verb/test.d/l1_filter` reads it and runs `cargo nextest run --all-features -E "$NEXTEST_FILTER"`.

`--dry-run` (first argument) prints the `.live` payload command and exits 0 — no tests run.

### Example

```bash
# Run a single test by exact name:
./verb/test1 test_config_get_existing_key

# Run all tests whose name contains a prefix:
./verb/test1 'test_config_'

# Dry run (prints command, no execution):
./verb/test1 --dry-run
```

`verb/test1` script:
```bash
#!/usr/bin/env bash
# test1 — run a single nextest filter inside the container.
set -euo pipefail
FILTER="${1:-}"
if [[ -z "$FILTER" ]]; then
  echo "error: usage: ./verb/test1 <nextest-filter>" >&2
  echo "  example: ./verb/test1 test_config_get" >&2
  exit 1
fi
if [[ "$FILTER" == "--dry-run" ]]; then echo "./runbox/runbox .live -- env NEXTEST_FILTER='<filter>' verb/test.d/l1_filter"; exit 0; fi
ROOT_DIR="$( cd "$( dirname "${BASH_SOURCE[0]}" )/.." && pwd )"
cd "$ROOT_DIR" && exec "$ROOT_DIR/runbox/runbox" .live -- env NEXTEST_FILTER="$FILTER" "$ROOT_DIR/verb/test.d/l1_filter"
```

`verb/test.d/l1_filter` (container-internal; entered as the `.live` payload with `NEXTEST_FILTER` set):
```bash
#!/usr/bin/env bash
# l1_filter — targeted single-filter test execution inside the container.
set -euo pipefail
SCRIPT_DIR="$( cd "$( dirname "${BASH_SOURCE[0]}" )" && pwd )"
cd "$SCRIPT_DIR/../.."
FILTER="${NEXTEST_FILTER:-}"
if [[ -z "$FILTER" ]]; then
  echo "error: NEXTEST_FILTER env var not set" >&2; exit 1
fi
export CARGO_NET_OFFLINE=true
export CARGO_TARGET_DIR="$PWD/target"
export NO_COLOR=1
export RUSTFLAGS="-D warnings"
exec cargo nextest run -p claude_profile --all-features --no-fail-fast -E "$FILTER"
```
