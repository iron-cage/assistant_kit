# Subcommand: rm

Delete a background session and its worktree.

> **Hidden subcommand** — functional in v2.1.220 but absent from `claude --help`. See [readme.md](readme.md) § Hidden Subcommands.

### Usage

```
claude rm <id>
```

### Arguments

| Argument | Description |
|----------|-------------|
| `<id>` | Background session identifier |

### Options

None. `--help` prints the usage line only; there is no options table.

### Sub-subcommands

None.

### Description

Deletes a background session together with its worktree. Its help text draws
the distinction explicitly: unlike [`claude stop`](019_stop.md), `rm` works on
sessions that have **already exited**. `stop` halts a running session and keeps
its conversation; `rm` removes the session outright.

**Destructive.** This deletes the session's worktree, not only its registry
entry.

Scope note: `rm` operates on one background session. To delete *all* Claude
Code state for a project — transcripts, tasks, file history, config entry —
the command is [`claude project purge`](011_project.md).

### Since

Unverified. No changelog entry in the `version/` collection records this

### Verification

```bash
claude rm --help              # → Usage: claude rm <id>

```
