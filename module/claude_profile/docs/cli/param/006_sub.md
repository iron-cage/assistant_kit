# Parameter: 6. `sub::`

Controls whether the subscription type line appears in output. Used by `.credentials.status` (from live credentials). No longer usable on `.accounts` — removed in [Feature 037](../../feature/037_accounts_usage_param_unification.md); `.accounts` now rejects `sub::` with `parameter 'sub' removed — use 'cols::-sub' instead` (see `REMOVED_TOGGLES` in `src/commands/accounts.rs`).

- **Default:** `1` (shown)
- **Constraints:** Accepted values: `0`, `1`, `false`, `true`
- **Purpose:** Allows suppression of the subscription type when only token validity or account name matters.

**Examples:**

```text
sub::1   → Sub:     max  (default)
sub::0   → line omitted
```
