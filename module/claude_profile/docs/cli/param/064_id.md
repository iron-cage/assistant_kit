# Parameter: 64. `id::`

Activates set mode on two commands, each writing a different key to `~/.clr/config.toml`'s user tier: on `.model.select`, pins the subprocess model (`model` key); on `.provider.select`, selects the global inference provider (`provider` key). When provided, activates set mode; when absent, the host command operates in read (get) mode unless `reset::1` is set.

- **Default:** *(omit)* — get mode; reads current preference from `~/.clr/config.toml`
- **Constraints:** Any non-empty string; on `.model.select` expected to be a full model ID (e.g., `claude-opus-4-8`); on `.provider.select` any provider name (e.g., `anthropic`, `kimi`) — no allow-list
- **Purpose:** Write a full model ID (`.model.select`) or a provider name (`.provider.select`) to `~/.clr/config.toml` for use by `clr run`/`clr ask`/`clr isolated`/`clr refresh` (model) or account rotation Gate 10 (provider).

**Values:**

On `.model.select`, any full model ID returned by `clp .models` is accepted. Common values:

| Value | Effect |
|-------|--------|
| `claude-opus-4-8` | Pin to Opus 4.8 for all clr task subprocesses |
| `claude-sonnet-5` | Pin to Sonnet 5 for all clr task subprocesses |
| `claude-haiku-4-5-20251001` | Pin to Haiku 4.5 for all clr task subprocesses |

On `.provider.select`, any non-empty provider name is accepted (free-form, no allow-list) — e.g., `anthropic`, `kimi`, `moonshot`.

**Validation:** Non-empty check at write time only. On `.model.select`, model validity is not checked against the live API at pin time — the Claude API will reject an invalid ID when clr invokes the subprocess. On `.provider.select`, no validity check beyond non-empty — any string is accepted since provider is a free-form label, not a filter.

**Error cases:**
- `id::` (empty value) → exit 1; stderr: `id:: must be a non-empty model ID` (`.model.select`) or `id:: must be a non-empty provider name` (`.provider.select`)
- `id::VALUE reset::1` together → exit 1; stderr: `id:: and reset::1 are mutually exclusive`

**Examples:**

```bash
clp .model.select id::claude-opus-4-8   # pin Opus 4.8
clp .model.select id::claude-sonnet-5   # pin Sonnet 5
clp .provider.select id::kimi           # select the kimi inference provider globally
```

**Notes:**
- On `.model.select`, `id::` governs the subprocess model for `clr run/ask/isolated/refresh`. For the interactive Claude Code session model, use `clp .model set::opus` instead.
- On `.provider.select`, `id::` sets the single global provider config value — never a filter, never derived; only this manual write changes it (see [param 073](073_inference_provider.md), [algorithm/004](../../algorithm/004_eligibility_gates.md) Gate 10).
- Run `clp .models` first to discover available full model IDs.
- The pinned/selected preference persists until explicitly reset with `reset::1` on the same command.
