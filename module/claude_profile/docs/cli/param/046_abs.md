# Parameter: 46. `abs::` — REMOVED

Removed. `abs::` was registered on `.usage` and `.accounts` for a planned absolute-token-count display but was never implemented — the parsed value was discarded and quota values always rendered as percentages. The dead surface (registration, parsing, validation) has been deleted; quota columns show percentages only.

**Migration:** none needed — `abs::0` (the default) and `abs::1` produced identical output. Passing `abs::` now fails as an unknown parameter; simply drop it.

**See Also:** [feature/009_token_usage.md](../../feature/009_token_usage.md) for quota column definitions.
