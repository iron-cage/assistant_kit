# Parameter: 46. `abs::`

Registered on `.usage` for a planned absolute-token-count display; currently a no-op — the parsed value is discarded and quota values always render as percentages.

- **Default:** `0`
- **Constraints:** `0`, `1`, `false`, `true`
- **Purpose:** Reserved for a planned absolute-token-count display; currently parsed and discarded (`let _ = params.abs;` in `api.rs`) — the quota table always shows percentages regardless of `abs::`.

**Behavior:** `abs::` is a registered no-op. Setting `abs::1` does not change the `.usage` table or `get::` output in any way — all quota columns (`5h Left`, `7d Left`, `7d(Son)`, etc.) continue to show percentages. This will take effect once the API exposes absolute count data.

**Examples:**

```text
abs::1                -> parsed and accepted; output unchanged (no-op)
abs::1 get::7d_left   -> parsed and accepted; still returns the 7d Left percentage, not a token count
```
